5. Design Philosophy

Everything follows CEMDS.

Design Principles:

Clarity over Aesthetic.

Confidence over Color.

Structure over Decoration.

Motion with Purpose.

Finance before Features.


No unnecessary decoration.

No visual noise.

Typography is the primary design element.

6. Color System

Light Theme

Background: White

Surface: Neutral 50

Text: Near Black

Border: Neutral 200

Primary: Emerald 600


Dark Theme

Background: Slate 950

Surface: Slate 900

Text: White

Border: Slate 800

Never use gradients as decoration.

Never use glassmorphism.

9. Scroll Storytelling

The landing page should unfold like a story:

1. The Problem — Manual reconciliation, scattered transfers, spreadsheets, and uncertainty. Animate floating payment cards and disconnected data.


2. The Solution — Payments begin flowing into order. Connections form, cards align, and a dashboard emerges.


3. How It Works — Visualize the payment pipeline: Parent → Bank App/USSD/POS → Dedicated Virtual Account → Payment Gateway → Webhook → Supabase → Offline Sync → Dashboard.


4. Financial Confidence — Animated KPIs count upward, outstanding balances decrease, and synchronization completes successfully.



Each section should transition smoothly, using motion to reinforce understanding rather than entertain.

11. Offline-First Section

Illustrate the core product philosophy:

1. Internet connection is lost.


2. The application continues operating locally.


3. An offline badge appears.


4. Changes are queued.


5. Internet returns.


6. Synchronization resumes automatically.


7. Queue clears.


8. System status returns to healthy.



Reinforce that only payment processing requires a live connection. Every other workflow remains operational.

16. Acceptance Criteria

The landing page is complete only if it:

Clearly positions CAPFLUX as a Financial Operating System.

Uses the complete landing page copy without diluting the messaging.

Follows the CAPFLUX Enterprise Minimalism Design System.

Supports both light and dark themes.

Uses motion intentionally to explain the product.

Performs well on desktop and mobile.

Meets accessibility standards.

Feels calm, premium, and trustworthy.
