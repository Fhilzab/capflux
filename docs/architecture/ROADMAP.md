# CAPFLUX Development Roadmap

## Vision

Build Africa's most reliable offline-first school finance and administration platform.

Core principles:

- Offline-first
- Multi-tenant
- Fast
- Secure
- Low bandwidth
- High contrast UI
- Mobile-first for parents
- Desktop-first for bursars
